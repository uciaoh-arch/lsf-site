隱私權政策

量師傅 / 找量師傅 共用政策 · 開發者: Yu Chiao Huang · v1.9 · 最後更新: 2026-10-15

本政策適用於以下兩款應用程式(以下合稱「本服務」),由 Yu Chiao Huang(以下稱「我們」)開發與維運,兩者共用相同後端與帳號系統:

  • 量師傅(iPad 版,Bundle ID com.ciao.lsf):供丈量/估價專業人士使用的付費訂閱工具,可註冊帳號。
  • 找量師傅(iOS,com.ciao.flsf):供一般民眾查詢測量服務人員的免費 App,僅能以既有帳號登入,不提供新註冊;其中「找測量人員」名單不需登入即可查詢。

我們重視使用者隱私,本政策說明本服務如何蒐集、使用、存放、公開與保護您的個人資料。使用本服務即表示您已閱讀並同意本政策。

一、核心隱私承諾

您在本服務中建立的丈量數據、工作表內容、公式、匯出的 PDF/Excel 文件等實際測量與文件資料,只會儲存在您的裝置上,我們不會將這些資料上傳、傳輸或備份到任何伺服器或雲端服務。 我們(或任何第三方)都無法讀取您的測量/文件內容。

以下情況為例外,且僅在您主動觸發時才會傳送,傳送前會先去識別化、移除個人資訊(同行範本另會移除實際測量數值):

  • 同行範本分享:您主動選擇將工作表「範本」分享給其他使用者時,系統只保留白名單內的內容:上方資訊卡片只留「工程項目」;下方只留快捷鍵與小計／合計／總計、樓層／項目／戶別。其餘一律清除(含計算式、實際測量數值、備註,以及案場、客戶、聯絡資訊與您自行輸入的其他文字)。我們的伺服器收到範本後會再檢查一次,偵測到疑似個資(電話、Email、地址、身分證、統編、稱謂等)或不在白名單內的內容時,整份拒收、不儲存、不發佈。
  • 手機平板連動資料夾(選用):首頁的「Google 雲端硬碟」「iCloud」兩個連動資料夾,只接收您以按鈕「複製」進來的檔案(不能移動、不能拖曳、不收資料夾);放進去的檔案會存到您自己的 iCloud 雲碟或您自己的 Google 雲端硬碟(資料夾「量師傅連動」),讓同一個帳號下的 iPhone 與 iPad 可以互相接續修改。這個過程不經過我們的伺服器,我們無法存取、保存或替您找回這些檔案;Google 只申請 drive.file 權限,登入憑證只存在您裝置的鑰匙圈;沒有放進連動資料夾的檔案一律只留在您的裝置上。
  • 提供模型訓練檔案(選用):您在首頁的「提供模型訓練檔案」資料夾內勾選檔案,不需另按上傳;勾選 30 秒後,App 在您的裝置上把該檔案整理成測量數據,只把整理後的數據(不是檔案本身)提供給我們的後台,用來訓練 AI 模型、精進測量功能;30 秒內取消勾選即撤回。頂端會常駐顯示條款、注意事項與本隱私說明。我們只收「測量工程房型數據」:工程類型、房間類別、樓層、各面尺寸與數量、算式與計算結果等數字與固定代碼;客戶姓名、地址、電話、Email、統編、公司名、案名、備註、檔名與任何自由輸入的文字一律不會上傳,您的原檔也不會離開裝置。我們的伺服器收到後會再檢查一次,偵測到疑似個資(電話、Email、地址、身分證、統編、稱謂、公司名)或不在允許清單內的欄位時整份拒收、不儲存。後台不儲存您的帳號識別(不記錄 user_id,也不記錄 IP 位址或裝置識別碼),因此已提供的資料無法連結到您,也無法個別撤回;超過 30 秒即已提供,事後刪除檔案都不會撤回。已提供過的檔案會標示「已提供」、不會重複提供。未訂閱(唯讀)的帳號不能使用此功能。您未主動勾選的其他量測資料,仍一律只留在您的裝置上。
  • 一鍵備份／導入(選用):您主動點選「備份」時,App 會把您裝置上的資料夾、檔案、備忘錄(含錄音)、範本、快捷字、警報門檻與各項設定打包成一個備份檔,只存到您自己選擇的地方(AirDrop、iCloud 雲碟等雲端、接線或 Wi-Fi 傳到電腦);這個過程不經過我們的伺服器,我們不會收到、保存這份備份檔,也無法替您找回遺失的備份。備份檔存放後的保管與外流風險由您自行負責;存到第三方雲端服務時,也適用該服務自己的條款與隱私權政策。「導入」會用您選擇的備份檔整個取代本機目前的資料與設定,執行前 App 會要求您確認三次,且會自動保留一份導入前的資料。
    • 自動備份到 iCloud(選用,預設關閉):您於備份頁主動開啟「自動備份到 iCloud」開關後,App 每天第一次離開或關閉時會在背景自動產生一份備份,寫入您自己 Apple 帳號下的 iCloud 雲碟(App 的 iCloud 容器內,資料夾「量師傅備份」),保留最近 14 份、超過自動刪除最舊的一份;這整個過程是您的裝置與您的 iCloud 之間直接發生,不經過我們的伺服器,我們無法存取這些備份。
    • 備份到 Google 雲端硬碟(選用):您主動登入 Google 並選擇「備份到 Google 雲端硬碟」後,備份檔會存到您自己的 Google 雲端硬碟,保留最近 14 份、超過自動刪除最舊的一份。App 只申請 drive.file 權限(只能存取 App 自己建立的檔案,看不到您雲端硬碟裡的其他檔案),登入憑證只存在您裝置的鑰匙圈;備份檔不經過我們的伺服器,我們無法存取,也無法替您找回。
    • 電腦備份提醒(選用):您於備份頁主動選定一個電腦共享資料夾後,App 會在偵測到您的裝置與該電腦處於同一 Wi-Fi 且可連線時,於前景跳出提醒詢問是否要備份一份過去;這個偵測與備份動作同樣只發生在您的裝置與您自己選定的電腦之間,不經過我們的伺服器。

「找量師傅」(iPhone 版)不具備任何量測、文件、資料夾功能,也不會讀取、同步或儲存您在量師傅(iPad 版)裝置上的任何量測與文件資料。兩個 App 之間唯一共通的是會員帳號、方案與廣告刊登相關資料;您的量測資料永遠只留在 iPad 裝置本機。

三之一、公開名單:「找測量人員」

公開名單只列出同時符合以下兩個條件的會員:(1)持有有效量師傅訂閱(Basic 以上方案,不論透過量師傅或找量師傅購買皆算)或持有尚未到期的置頂名額,且 (2)送出「廣告刊登」(送出後即上架顯示)。符合條件時,您在刊登內容中填寫的姓名、電話、LINE ID(若填寫)與測量區域會公開顯示於量師傅與找量師傅的「找測量人員」名單及置頂版位,任何使用者(包含未登入的一般民眾)都可以查詢並直接取得上述聯絡方式。訂閱到期或刊登被下架後,您會立即從「找測量人員」名單之一般列示移除;已購買且尚未到期之置頂名額不受影響,仍會照常顯示您的聯絡資訊至該置頂名額期限屆滿為止。重新訂閱後即恢復名單一般列示。

單純在註冊時填寫工作區域,不會讓您被列入名單——那只是之後送出廣告刊登時的預設欄位,實際公開只發生在您送出刊登的那一刻。這是本服務媒合一般民眾與測量服務人員的核心機制,請只在刊登內容中填寫您願意公開的聯絡資訊。

  • 同意方式:分兩處請您明確勾選同意(個資法第 8 條告知),文字定案如下:
    • (a) 註冊表單填寫工作區域時(AccountAuthView,iPad/iPhone 共用):「我了解:填寫工作區域不會立即公開。只有在我之後送出「廣告刊登」後,我的姓名、電話與 LINE ID 才會公開顯示於找測量人員名單。詳見〈隱私權政策〉。」
    • (b) 廣告刊登表單送出前:「我了解並同意:此刊登送出後,我的姓名、電話與 LINE ID 將公開顯示於找測量人員名單及置頂版位,供所有使用者查看聯絡;內容真實且我有權公開。」
  • 退出方式:您可以隨時在 App 內自行下架刊登或來信 uciaoh@gmail.com 要求下架,或等訂閱到期/取消後自動自名單一般列示移除。下架後名單即不再顯示,但已被其他使用者記下的資訊我們無法追回。
  • 下架後,您仍可正常使用本服務其他功能,僅「找測量人員」名單上的曝光機會會消失。

給瀏覽名單的一般使用者:您在「找測量人員」名單看到的聯絡資料,是測量人員自行送出廣告刊登後公開的聯絡資料,目的是讓您能直接聯繫該測量人員洽詢丈量/估價服務。這些資料並非我們蒐集自您,也不會因您瀏覽而產生任何屬於您的個人資料紀錄;未登入瀏覽名單時,我們不會蒐集您的姓名、帳號等身分資料;唯為防止濫用,伺服器會暫存來源 IP 位址進行速率限制(見第二節)。請僅將這些聯絡資料用於洽詢測量服務,不得抓取、彙整、轉售或用於行銷(詳見服務條款「廣告刊登與名單」)。

置頂成效統計:置頂版位得主可在 App 內查看該版位被瀏覽與撥打電話的匿名累計次數。我們只記錄以週為單位的累計次數與最後更新時間,不會記錄查看或撥打者的身分、IP 位址或裝置資訊,無法從這份統計資料反推是誰查看或撥打;這與上方第二節表格所列、僅用於速率限制/防濫用的 API 呼叫端 IP 記錄是不同的機制與用途。

三之二、AI 分析(裝置端自有模型)

量師傅的「AI 分析」使用量師傅自行訓練、內建在 App 內的小型模型,在您的裝置上運算:檔案內容不會傳送給任何第三方 AI 服務,也不會上傳到我們的伺服器,不需要輸入任何 API Key。模型的訓練資料來自內政部不動產成交案件實際資訊(實價登錄)開放資料,依「政府資料開放授權條款－第1版」提供,資料來源:內政部;以及您自願複製進「提供模型訓練檔案」資料夾的去識別化檔案(見上方說明)。分析結果只顯示在畫面上、不儲存,每次按「AI 分析」重新計算。AI 分析的結果僅供參考,不構成估價、鑑價或任何專業意見,最終丈量數據仍以您的實際量測為準。

四、資料保存期間與刪除帳號

  • 帳號相關資料於帳號存續期間保留。
  • 刪除帳號:您可以在任一 App 的「帳號」頁選擇「刪除帳號」。刪除後我們會移除您的登入憑證,並在 30 日內刪除或去識別化帳號資訊、廣告刊登資料與方案紀錄;已公開的刊登會立即下架(法令要求保留者除外,例如交易紀錄之法定保存義務)。
  • 裝置上暫存的帳號相關資料:為了離線時仍能判斷您的方案,App 會在您的裝置上暫存「方案層級、到期日、是否為體驗期」(量師傅:訂閱到期後另有 3 天寬限;找量師傅:最多沿用 7 天,且綁定目前登入的會員),另有姓名顯示偏好與尚未送出的廣告表單草稿。這些只存在您的裝置,不上傳;登出或刪除帳號時 App 會一併清除(刪除帳號另會撤銷所有裝置上的登入)。裝置時間被往回調時,離線暫存不被採信,需連網確認。刪除帳號不會刪除您裝置上的量測檔案。
  • 刪除帳號不會取消您在 App Store 的自動續訂訂閱——請務必先於「設定 > Apple ID > 訂閱」取消,否則 Apple 仍會依原週期扣款。已購買但未使用的消耗型額度與置頂名額會隨帳號刪除而失效,無法退還(退款請依 Apple 政策向 Apple 申請)。
  • 刪除紀錄:帳號刪除後,我們會另外保留一筆不含個資的刪除紀錄,內容僅為:以密鑰雜湊(hash)處理過的信箱識別碼、刪除時間、刪除時使用之 App、刪除當下是否持有有效訂閱/置頂名額。此紀錄無法逆向還原出您的 Email 或其他個人資料,用途僅限於帳務對帳與退款爭議處理,保存期限為刪除後2 年(如刪除時已有進行中之帳務爭議或法律程序,則延長保留至該爭議/程序終結為止),期滿後刪除。
